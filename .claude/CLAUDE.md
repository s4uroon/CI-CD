# Instructions spécifiques au projet pour Claude

## ⚠️ Règle stricte : Mise à jour de la documentation

**Tu DOIS systématiquement mettre à jour le fichier `README.md` chaque fois que tu apportes une modification au code du projet.** Que ce soit pour l'ajout d'une nouvelle fonctionnalité, la modification d'un comportement existant, ou la suppression de code obsolète, la documentation doit toujours rester synchronisée avec l'état actuel du dépôt.

### Ton processus de travail lors d'une modification :
1. **Comprendre et coder :** Effectue les modifications de code demandées.
2. **Évaluer l'impact :** Demande-toi comment ces modifications affectent le projet (nouvelles commandes, nouvelles variables d'environnement, changements d'architecture, nouvelles dépendances, etc.).
3. **Mettre à jour le README.md :** - Ajoute, modifie ou supprime les sections correspondantes dans le `README.md`.
   - Si la modification est mineure et ne change pas l'usage du projet, ajoute au moins une ligne dans une section "Changelog" ou "Dernières modifications" (si elle existe) pour garder une trace.
4. **Finaliser :** Ne considère jamais ta tâche comme terminée tant que le `README.md` n'a pas été actualisé en conséquence.
